# Google Cloud Sidecar Containers
I created a sample application of Spring Boot and Nginx server to utilize Cloud Run's sidecar containers feature. This feature allows developers enhanced control over security, resource optimization, and application architecture.

You can read more about this approach in the following articles:

[Cloud Run Sidecar Blog](https://cloud.google.com/blog/products/serverless/cloud-run-now-supports-multi-container-deployments)

[GCP Cloud Run Sidecar documentation](https://cloud.google.com/run/docs/deploying#sidecars)

I have written an article on how we can leverage this feature to enhance the security of the application using sidecar containers. You can find it on [Cloud Run Sidecar](https://medium.com/google-cloud/enhancing-web-application-security-with-cloud-run-sidecar-containers-1f40a6a324f0)
